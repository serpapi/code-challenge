SUMMARY - initial working code for given input
    I parsed the provided HTML file directly using BeautifulSoup and extracted:
    - painting name
    - extensions array (year)
    - Google link
    - thumbnail image when the thumbnail is actually present in the HTML file

    The main difficulty in this challenge was thumbnail extraction.
    Some paintings in the provided HTML contain only:
    - a placeholder gif in the img src
    - data-deferred="1"

    This indicates lazy/deferred image loading. In those cases, the real thumbnail
    is not actually present in the saved HTML file.

    My solution only includes thumbnails that are directly available in the HTML. 
    The expected array appears to contain real image data for some items whose
    provided HTML only contains deferred placeholder gifs. This suggests that the
    expected array may have been generated from a more fully rendered browser state
    than the raw saved HTML file.

SUMMARY - working code for extra examples 
    Examples Used: 
        -I used a similar Monet Paintings html from Google for example 1 
        -I used Shakespeare Plays for example 2 to show differing layout
    I initially implemented a scraper using fixed class selectors (e.g., iELo6, pgNMRc, cxzHyb), 
    which worked for the Van Gogh paintings page but failed on other layouts.
    To generalize the solution, I added fallback, so that the scraper can find the relevant carousel section 
    based on headings like “Artworks” or “Plays,” and then extract individual cards within that section.
    Instead of relying solely on class names, I used links, images, and short text patterns to identify titles and years.
    I also added filtering to avoid large container elements, which caused incorrect outputs initially when testing this. 

    Now the scraper works across multiple Google Knowledge Graph carousel layouts.
